# Gigatron Web Tools

Public repository for Gigatron emulator, rombuilder and showcase phpBB extensions.

## Components
- gigatronemulator/ - Web-based Gigatron emulator extension
- gigatronrombuilder/ - Web-based Gigatron ROM creation extension
- gigatronshowcase/ - Gigatron showcase extension

## Status
Work in progress - ready for testing.
